# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
本專案採用 [Contributor Covenant 2.1 版](https://www.contributor-covenant.org/zh-tw/version/2/1/code_of_conduct/)行為準則。

## In short

- Be respectful and welcoming. Assume good intent, and critique ideas, not people.
- No harassment, discrimination, personal attacks or sexualised language, in any project space (issues, pull
  requests, discussions, reviews).
- Do not publish other people's private information. In this project that includes images or recordings of
  people captured with the demo.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainers privately through the repository
host (for example GitHub's *Report content* feature, or a private message to a maintainer listed on the
repository). Reports are handled confidentially. Maintainers may remove content and restrict participation as
described in the Contributor Covenant's enforcement guidelines.
