# 互動意圖（Layer 3，`intent_model=score`）

`intent_model` 決定一個人什麼時候成為**參與者**（join）：

| 值 | 說明 |
|---|---|
| `rules` | **預設**，行為不變：在 ROI 待滿 `join_seconds` 就加入，`speech_join` 可以讓說話的人立即加入。 |
| `score` | 每個 track 有一個 0–1 的**互動意圖分數**。分數 ≥ `join_threshold` 並持續 `join_seconds` 才加入；分數長時間太低，參與者會降為**旁觀者**。 |

`score` 可以搭配任何追蹤模式和在場模型，建議搭配 `tracker_mode=kalman` 和 `presence_model=hmm`。

程式位置：
- `presence_demo/intent.py`：純數學；
- `tracker.py` 的 `_update_intent`／`_join_and_drop`。

不需要任何模型權重，只使用已經有的偵測結果，可商用。

## 線索（每個都是 0–1）

| 線索 | 計算 | 權重參數（預設） |
|---|---|---|
| 面向 facing | 有臉：YuNet 五點的「鼻子偏離雙眼中點 ÷ 眼距」（0 → 1 分，≥ 0.5 → 0 分）；沒有五點時用 0.85。有姿勢：和肩膀方向分數各占一半。沒有臉：只用肩膀方向分數。 | `w_facing` 0.45 |
| 距離 distance | 在對話區（≤ `zone_max`）＝1，到 `leave_distance` 線性降到 0。**距離估計關閉時這個線索直接略過**，其他權重自動重新正規化。 | `w_distance` 0.1 |
| 停留 dwell | 在 ROI 的秒數 ÷ 4 s，最高 1 | `w_dwell` 0.1 |
| 走近 approach | 0.5 + 4 × 身體大小的相對變化率（每秒），限制在 0–1。變大＝走近 | `w_approach` 0.05 |
| 沒在路過 still | 1 − \|橫向速度\| ÷ 0.12（畫面寬／秒），最低 0。kalman 模式用 Kalman 速度，legacy 模式用中心點差分的 EMA | `w_still` 0.15 |
| 位置 center | 1 − 和 ROI 中心的正規化距離（垂直方向權重減半） | `w_center` 0.15 |
| 說話 speech | 正在說話，**而且**能合理歸屬給這個人（畫面裡只有一位候選人，或他是唯一面向機器人的人）時＝1；否則不計入（不會扣分）。 | 依 priority_mode：vision 0.05、balanced 0.15、audio 0.25 |

### 分數

1. **加權平均**：`raw = Σ wᵢ·cueᵢ ÷ Σ wᵢ`，只算有值的線索。
2. **注意力閘門**：`raw × (1 − 0.5 × (1 − facing))`。背對的人即使站很久、站在中間，也很難拿到高分。
3. **平滑**：用實際時間差計算 `intent ← intent + (raw − intent) × (1 − e^(−dt/intent_tau))`，和 fps 無關。
   - 新的 track 從第一幀的 raw 開始。
   - 看不到時不會有新的證據，只用 4 倍的時間常數慢慢往 0 掉。

## 用法

- **加入**：`intent ≥ join_threshold`（0.6）持續 `join_seconds`（2 s），而且這一幀有偵測到、不是 far。說話不會再讓人「立即加入」，只是一個弱線索。
- **開始對話**：
  - ENDED 時，要有人達到加入條件才開始新的 session（路人不會開始對話）；
  - balanced／audio 模式仍然可以用說話開始；
  - 和 rules 相比，開始時間大約晚 `join_seconds`。
- **降為旁觀者**：參與者的 `intent < drop_threshold`（0.35）持續 `drop_seconds`（8 s），而且這段期間有看到他，就降為旁觀者。
  - **最後一位參與者不會被降級**：人是否離開由 Layer 2 判斷，避免一直側身講話的人被判定離開。
- **在場（hmm）**：群組 P 只看參與者；旁觀者不會讓對話一直持續。
  - 還沒有參與者時，只看意圖已經 ≥ 門檻的 track。
  - `intent_weighted_presence`（預設關閉）：參與者的 P 乘上 `min(1, intent ÷ join_threshold)`。
- **NEW_GROUP**：新候選人除了原本的條件，還要達到加入條件（意圖 ≥ 門檻並持續 `join_seconds`）。

state 中每個 track 新增：
- `intent`：意圖分數；
- `intent_cues`：各線索的值；
- `role`：`participant`（參與者）或 `bystander`（旁觀者）。

網頁：
- 每個人有一條意圖條，白線是加入門檻；滑鼠移到上面會顯示各線索；
- 標籤顯示「參與者」或「旁觀者」；
- 設定中有「互動意圖」分組。

### 解讀

- **意圖分數解決了「旁人」問題**：
  - 誤加入從 60 降到 0（路人、旁觀者、滑手機的人各 20 次）。
  - 參與者離開後，三個 rules 版本都被旁人撐住、**一直不判定離開**（各 20 次沒判定）；score 在 5.0 s 判定 AWAY。
- **代價**：
  - 「新來的人走近並說話」加入時間 3.0 s，rules 是 2.0 s：要先走近、轉正、分數穩定。
  - 在旁觀者情境，session 結束時會清空所有 track，旁人之後被重新追蹤成新的 id，所以「斷裂」計數是 20。這是設計如此，不是追蹤錯誤。
- **其他情境**：結果和 kalman+hmm 相同，沒有退步。三人一組其中一人離開時，沒有誤判，也沒有 NEW_GROUP。
- **限制**：
  - 合成情境裡「旁觀者」的臉偏角和肩膀方向是設定好的，真實情況的分布需要實際觀察。
  - 正面直視、站在 ROI 中間、但其實不想互動的人，仍然會被當成參與者（只看影像無法分辨）。

## 建議

- 意圖分數明顯減少旁人誤加入，也避免旁人讓對話一直不結束，適合公共空間。
- 建議組合 `tracker_mode=kalman` + `presence_model=hmm` + `intent_model=score`。先在網頁切換並觀察每個人的意圖條，確認實際的分數分布（特別是側站觀看的人）後，再改成預設值。
- 如果覺得加入太慢，可以降低 `join_threshold`（例如 0.55）或 `intent_tau`。
- 如果旁人常被誤加入，可以提高 `w_facing` 或 `join_threshold`。
